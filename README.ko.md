# switch-remote

[English](README.md) · [다운로드](https://github.com/hada0127/switch-remote/releases/latest)

캡처카드로 받은 스위치 화면을 맥에서 보고 소리도 들을 수 있는 앱입니다. 맥에 연결한 패드로 스위치를 조작하려면 라즈베리파이 Zero W를 추가하면 됩니다.

이전 이름은 Video Game Filter입니다. 기존 설정과 저장한 프리셋은 그대로 사용할 수 있습니다. 새 앱을 설치한 뒤에는 이전 앱을 응용 프로그램 폴더에서 지워두면 잘못 실행하는 일을 피할 수 있습니다.

## 준비물

- macOS 14 이상을 사용하는 Apple Silicon 맥
- macOS에서 사용할 수 있는 캡처카드, HDMI 케이블, 스위치 독
- 패드 입력을 전달하려면 라즈베리파이 Zero W, microSD 카드, USB 데이터 케이블

화면과 소리만 보고 들을 때는 파이가 필요 없습니다. 파이는 패드 입력을 스위치로 보내는 역할입니다.

## 처음 실행하기

1. [최신 릴리즈](https://github.com/hada0127/switch-remote/releases/latest)를 내려받고 압축을 풉니다.
2. `switch-remote.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
3. 스위치 독의 HDMI 출력을 캡처카드에 연결하고, 캡처카드를 맥에 연결합니다.
4. 카메라와 마이크 권한을 요청하면 허용합니다. 캡처카드의 영상과 소리를 받는 데 필요합니다.
5. 화면을 클릭하면 설정이 열립니다.

설정은 **기본 / 레트로 효과 / 컨트롤러** 세 탭으로 나뉩니다.

## 기본

비디오 장치, 오디오 장치, 해상도와 프레임률을 선택합니다. 화면은 나오는데 소리가 없다면 오디오 장치부터 확인하세요.

선택할 수 있는 해상도는 캡처카드에 따라 다릅니다. TV로 4K60 신호를 통과시키는 제품이어도 맥에 들어오는 영상은 더 낮을 수 있습니다. 예를 들어 Elgato HD60 X의 캡처는 최대 4K30입니다.

**Control–Command–F**를 누르면 전체화면으로 전환합니다. **×**로 설정을 닫고, 화면을 클릭해서 다시 열 수 있습니다. 마우스를 3초간 움직이지 않으면 커서가 숨겨지고, 움직이면 다시 나타납니다.

## 레트로 효과

먼저 프리셋을 골라보세요.

- **원본:** 효과 없이 표시합니다.
- **CRT · 기본:** 기본 CRT 느낌입니다.
- **CRT · 기본 (세로):** 기본 CRT의 스캔라인 방향을 세로로 바꿉니다.
- **CRT · 선명하게:** CRT 효과를 가볍게 적용합니다.
- **가로 스캔라인 25% / 그리드 27%:** 가로줄 또는 격자무늬를 적용합니다.

가로줄과 세로줄의 강도, 두께, 간격을 따로 조절할 수 있습니다. CRT를 켜면 화면 곡률, 빛 번짐, 가장자리 음영, RGB 마스크도 조절할 수 있습니다. 안티앨리어싱은 게임 영상을 부드럽게 하며 스캔라인과 마스크에는 영향을 주지 않습니다. 선명한 확대 옵션도 있습니다.

마음에 드는 설정은 **새 프리셋 저장**으로 저장하세요. **덮어쓰기**는 선택한 사용자 프리셋을 바꾸고, **삭제**는 지웁니다. 기본 제공 프리셋은 덮어쓰거나 삭제할 수 없습니다. 처음 설치하면 CRT · 기본으로 시작하며, 기존 사용자의 설정은 유지됩니다.

## 컨트롤러

맥에 연결한 패드의 입력을 파이가 받아 스위치로 보냅니다. 파이와 독은 USB로 연결하는 것을 권장하며, 블루투스 연결도 지원합니다.

1. Raspberry Pi Imager로 **Raspberry Pi OS Lite 32비트(Bookworm 이상)**를 SD 카드에 설치합니다. 파이의 **2.4GHz Wi-Fi**도 설정합니다.
2. SD 카드가 맥에 연결된 상태에서 컨트롤러 탭의 **새 파이 SD 준비…**를 누르고 `bootfs` 볼륨을 선택합니다.
3. 카드를 안전하게 추출해 파이에 넣습니다. 파이의 **USB 데이터 포트**와 스위치 독을 데이터 케이블로 연결합니다. 다른 micro-USB 포트는 전원 전용입니다.
4. 첫 부팅은 몇 분 기다려주세요. 최초 설정에는 인터넷이 필요합니다. 맥의 로컬 네트워크 권한을 허용하고, 맥과 파이를 같은 네트워크에 연결합니다.
5. 패드를 맥에 연결하고 **입력 장치**에서 선택합니다. 자동 연결을 켜 두면 다음에도 저장된 파이에 다시 연결합니다.

A/B와 X/Y가 반대로 느껴지면 **A/B · X/Y 맞바꾸기**를 켜세요. 맥에 직접 연결한 패드는 앱이 활성화된 동안 입력을 보냅니다. HOME·캡처·L+R은 어느 설정 탭에서든 바로 누를 수 있습니다.

블루투스로 처음 연결할 때는 스위치의 **컨트롤러 → 잡는 방법/순서 변경** 화면을 여세요. USB 연결이 안 되거나 자세한 설정이 필요하면 [파이 안내](controller/README.md)를 참고하세요.

스위치 2 슬립 깨우기, 진동, 모션 조작, NFC는 지원하지 않습니다. 스위치를 먼저 켜고 연결해주세요.

## Moonlight 간단 안내

Moonlight로 아이폰이나 안드로이드 기기에서 맥 화면을 볼 수 있습니다. 원격 패드 입력에는 [수정된 Sunshine 도우미](controller/sunshine/README.md)가 필요합니다. 별도로 설정해야 하며 이 앱 다운로드에는 포함되지 않습니다. 앱의 입력 장치에서 **문라이트 · 선샤인**을 선택하세요.

집 밖에서 접속하려면 두 기기를 Tailscale에 연결하고, Moonlight에 맥의 Tailscale 주소를 추가합니다. 맥·앱·파이·스위치는 켜 두어야 합니다. 집 안 Wi-Fi에서 되는 것과 외부 접속은 별개이므로, 외부에서도 영상과 조작을 확인해주세요.
