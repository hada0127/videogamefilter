## Introduction
This program can set scanlines on screens coming in through external video and audio input devices, such as HDMI capture cards. 
It was created for people who love retro games, including me.😛

## Native macOS 0.3.0

A lightweight SwiftUI/Metal capture-card viewer with CRT effects, bloom strength/radius,
independent horizontal/vertical scanline controls, whole-video smoothing, resolution
selection, audio playback, full screen and saved effect presets. Hada Sans is bundled.
New installations start with the tuned **CRT · 기본** preset; existing settings are preserved.

- macOS 14 or later, Apple Silicon (arm64)
- Capture resolution/frame rate depends on the device. HD60 X captures up to 4K30, not 4K60.
- This is a viewer; controller emulation, recording and streaming are not included.
- Build instructions and effect details: [macOS/README.md](macOS/README.md)

## How to use
1. Run the program.
2. Select a video input device.
3. Select an audio input device.
4. Set the horizontal and vertical scanlines to your preference.
5. Enjoy 😄

👏 MacOS users, please grant the camera and microphone permissions if requested.
